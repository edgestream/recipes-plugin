# Recipes 0.1.1 release notes

Recipes 0.1.1 is the first deployable stable release candidate. It packages the
Recipes MCP server and CLI for maintaining a personal recipe collection and for
finding and importing provider recipes.

## Highlights

- Search, retrieve, import, list, and delete recipes through the bundled MCP
  server.
- Use the same service through the bundled `recipes` CLI.
- Search and import Chefkoch recipes while keeping source URLs separate from
  provider-qualified recipe identities.
- Run the optional Streamable HTTP MCP transport for a controlled, single-user
  deployment.

## Correction from 0.1.0

- Hosted Chefkoch requests on Node.js 24 now return the validated pinned DNS
  address in the callback shape requested by Node. This preserves host
  allowlisting, public-address validation, DNS pinning, request limits, and
  credential-header stripping while restoring hosted search and imports.
- The unused 0.1.0 GitHub release was withdrawn after this defect was found.
  GitHub's immutable-release rules prevent reusing that release tag, so this
  correction is published as 0.1.1.

## Compatibility and installation

- Node.js 24 or later is required for the bundled runtime.
- There is no supported stable update path from 0.1.0 because that candidate
  was withdrawn before deployment or use.
- The stable plugin identity is `recipes` (`Recipes`). It is intentionally
  separate from the development identity `recipes-dev` (`Recipes Dev`), so an
  existing development installation and its settings do not migrate
  automatically.

## Release boundaries

- Marketplace promotion is not part of this release candidate. A stable
  marketplace entry must be created only after the immutable `0.1.1` tag and
  GitHub release are published.
- ChatGPT Directory publication, workspace provisioning, closed-group access
  validation, and the hosted deployment checks tracked by #34 are not included.
- Backup and restore remain deferred; this release makes no recovery claim.

## Verification

Release preparation verifies synchronized package, manifest, runtime, and
bundle metadata. The exact tagged commit must additionally pass the repository
build, type check, tests, bundle handshakes, and ARM64 container smoke check
before publication.
